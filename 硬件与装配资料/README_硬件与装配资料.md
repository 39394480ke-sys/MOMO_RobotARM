# 硬件与装配资料

本目录是阶段十二的资料包，用来把前面阶段的软件系统整理成可以装配、检查和维护的项目文档。

本项目参考第三方 SOARM MOCE 硬件资料。以下信息用于硬件兼容和安全调试，发布前需要核验原始资料的许可证、署名要求和再分发限制：

| 关节 | 内部 key | 中文名称 | 舵机 ID | 模式 |
|---|---|---|---:|---|
| J10 | `j10` | 底盘导轨 | 10 | 多圈 |
| J11 | `j11` | 底座旋转 | 11 | 多圈 |
| J12 | `j12` | 肩部抬升 | 12 | 多圈 |
| J13 | `j13` | 肘部弯曲 | 13 | 多圈 |
| J14 | `j14` | 腕部俯仰 | 14 | 多圈 |
| J15 | `j15` | 腕部旋转 | 15 | 多圈 |
| J16 | `gripper` | 夹爪 | 16 | 单圈预留 |

V2 的主链 J10-J15 均为多圈。权威 joint scales 为：

```yaml
j10: 28.8
j11: 5.0
j12: -28.0
j13: 13.0
j14: 1.0
j15: 1.0
```

完整映射以 `配置/robot_v2.yaml` 为准；V1 使用 `配置/robot_v1.yaml`。V2 J12/J13
的逻辑范围还要根据当前 Home 与 `±30719` raw 上限动态计算，不能只看静态配置。

协议参数固定为：

```text
RAW_COUNTS_PER_REV = 4096
MULTI_TURN_PHASE_VALUE = 28
MULTI_TURN_ABSOLUTE_RAW_LIMIT = 30719
POSITION_MODE_VALUE = 0
```

## 使用顺序

1. 先读 `发布资料/最终README.md`，理解项目边界。
2. 按 `硬件清单_BOM.md` 核对零件。
3. 按 `装配步骤.md` 装配，缺照片的位置先标记。
4. 按 `接线记录.md` 接线，上电前逐项执行 `安全检查清单.md`。
5. 先仿真和 dry-run，再按 `标定流程.md` 为每个真实硬件阶段取得单独明确批准。
6. 严格按 ping、只读 raw、核对零位、单关节微动、停止/关闭扭矩、低速多关节执行。

默认原则：先仿真，后 dry-run，最后才是真实机械臂。
