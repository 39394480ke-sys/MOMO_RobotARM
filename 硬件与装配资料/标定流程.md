# 标定流程

本页只定义安全顺序。实际操作前先阅读
[`../docs/V2真机验收.md`](../docs/V2真机验收.md)，并为每个硬件阶段取得单独明确批准。
本轮文档更新没有连接、读取或驱动真实硬件。

## 准备

- 明确选择 V1 或 V2；默认 V2，权威配置为 `配置/robot_v2.yaml`。
- 受控 `真实舵机控制/真实配置.yaml` 保持串口为空、`dry_run: true`。
- 实际串口只放在被忽略的本地配置或 `ARM_ROBOT_PORT`。
- 实际标定只保存为被忽略的 `真实舵机控制/标定/current.local.json`。
- `标定/v1.example.json`、`标定/v2.example.json` 只是模板，绝不能用于真机。
- 清空工作区，固定机械臂，确认电源、接线、急停和断电手段。

## 分阶段执行

1. 经批准后 ping，仅确认设备与 ID 在线。
2. 另行批准后只读 raw，核对位置、温度、电压和通信状态。
3. 另行批准后建立或核对机械零位，生成带准确 `_meta.robot_variant` 的本地标定。
4. 另行批准后以低速进行单关节微小运动，核对方向、回读、限位和停止。
5. 另行批准后停止并关闭扭矩，确认状态。
6. 另行批准后才进行小范围、低速多关节运动。

任一阶段异常都立即停止，不得跳级。写寄存器、读取状态和运动不是同一个批准范围。

## V2 特别检查

V2 的 J10-J15 均为多圈。J10 应保留并复核既有标定；J11-J15 按 CAD 零位建立 Home。
J12/J13 的逻辑可达范围必须由当前 Home、传动映射和绝对 raw 上限 `±30719` 动态计算，
并且始终严于或等于静态配置范围。这个门禁不能绕过。

标定文件只有 `_meta.robot_variant` 与当前型号完全匹配时才可进入真机路径。该字段
缺失、未知或不匹配时，只能仿真或 `dry_run` 预览，不能通过修改旧文件绕过检查。
动作文件使用的是顶层 `robot_variant`，不是 `_meta.robot_variant`。
