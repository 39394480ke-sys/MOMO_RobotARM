# Web AI 对话页布局优化设计

## 目标

在不改变 AI 对话、语音输入、动作确认和机械臂控制逻辑的前提下，简化 AI 对话页并修复 Agent 配置区域被长 URL 撑开的布局问题。

## 页面调整

- 删除对话区下方的“环绕运镜”“生成海报”“查状态”“安全说明”快捷按钮组。
- 保留顶部“刷新状态”“清空聊天”“重置会话”操作。
- 保留对话记录、语音输入、文字输入、发送按钮和动作二次确认卡。
- 桌面端使用主次两栏布局：对话区为主要区域，Agent 配置区为较窄的辅助区域。
- 窄屏下两栏自动改为上下排列。

## Agent 配置布局

- 配置项继续使用现有 `dl` 语义结构。
- 标签列保持稳定宽度，值列使用 `minmax(0, 1fr)`，避免内容反向撑大网格。
- API、STT、TTS 等长文本允许在任意合适位置换行。
- 配置面板和其网格子项设置正确的最小宽度，避免横向溢出和遮挡。

## 实现范围

- 修改 `Web控制台/frontend/index.html`，移除快捷按钮容器。
- 修改 `Web控制台/frontend/styles.css`，优化 AI 页面网格、配置键值布局及响应式规则。
- 删除 `app.js` 中只服务于已移除快捷按钮的事件绑定。
- 将同样的前端修改同步到当前运行的 `/tmp/momo-v2-web-voice` 副本。

## 验证

- 桌面视口检查页面无横向溢出，长 URL 完整换行。
- 移动视口检查两个面板上下排列，输入区和顶部操作不重叠。
- 检查快捷按钮不再出现在 DOM 中。
- 验证刷新状态、清空聊天、重置会话以及文字输入仍可用。
- 检查浏览器控制台无相关错误。
